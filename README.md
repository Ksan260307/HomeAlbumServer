# ホームアルバム

このPCに保存している写真や動画を、**家の Wi-Fi につないだスマホや他のパソコンから見られる**ようにするアプリです。

- 写真・動画をアルバムのように一覧で見られます
- 1枚ずつでも、まとめてでもダウンロードできます
- フィルターや明るさの調整、切り抜きなどで写真を編集できます
- 用紙やレイアウトを選んで写真を印刷できます
- スマホから写真や動画をアップロードできます（許可したフォルダだけ）
- 見せたいフォルダはいくつでも登録できます
- 家のネットワークの外（インターネット）からは見られません

---

## はじめる前に（最初の1回だけ）

1. **Node.js（ノード・ジェイエス）をインストールします。**
   [https://nodejs.org/](https://nodejs.org/) を開き、「LTS」と書かれたボタンからダウンロードしてインストールしてください。
   インストール中の設定はすべてそのまま「次へ」で大丈夫です。

---

## 起動する

1. このフォルダの中にある **`start.bat`** をダブルクリックします。
2. 黒い画面が開きます。初回だけ準備に1〜2分かかります。
3. 準備ができると、ブラウザが自動で開きます。

> **「Windows セキュリティの重要な警告」が出たら**
> 「プライベート ネットワーク」にチェックが入っていることを確認して、**「アクセスを許可する」** を押してください。
> これを許可しないと、スマホから見られません。

> **「WindowsによってPCが保護されました」と出たら**
> 「詳細情報」→「実行」を押してください。

---

## 最初の設定

初めて起動すると、**管理画面** が開きます。

1. **管理用パスワードを決めます。**
   フォルダの登録など、設定を変えるときに使います。忘れないようにしてください。
2. **「フォルダを追加」** を押して、見せたい写真や動画が入っているフォルダを選びます。
   - 「ピクチャ」「ビデオ」などの場所から、フォルダをクリックして開いていきます。
   - 目的のフォルダを開いたら **「このフォルダを追加」** を押します。
   - アルバムに表示する名前も、ここで変えられます。
3. 必要なら、フォルダごとに次のスイッチをオンにします。
   - **アップロードを許可** … スマホなどから写真・動画を追加したり、フォルダを作ったりできるようになります
   - **削除・名前変更を許可** … スマホなどから写真・動画の削除や名前の変更ができるようになります

   どちらもオフのフォルダは「見る・ダウンロードするだけ」になります。

フォルダはいくつでも追加できます。「登録を外す」を押してもアルバムに表示されなくなるだけで、**フォルダや写真は消えません**。

---

## スマホや他のPCから見る

1. スマホやPCを、**このPCと同じ Wi-Fi** につなぎます。
2. 管理画面の一番上にある **QRコードをスマホのカメラで読み取ります**。
   （または、表示されているアドレス `http://192.168.○○.○○:8080/` をブラウザに入力します）
3. アルバムの一覧が表示されます。

> ブラウザの「ホーム画面に追加」や「ブックマーク」をしておくと、次から簡単に開けます。

### QRコードを印刷して貼っておく
管理画面の **「QRコードを印刷」** を押すと、QRコードを紙に印刷できます。冷蔵庫や棚に貼っておけば、家族や遊びに来た人もスマホで読み取るだけで開けます。

- **大きく1枚（A4）** … 見出し・QRコード・使い方の説明を A4 用紙1枚に大きく印刷します
- **カード8枚（切り取り用）** … 名刺くらいの大きさのカードを8枚印刷します。点線で切り取って配れます
- 見出し（例：「田中家のアルバム」）と、つなぐ Wi-Fi の名前を入れられます（Wi-Fi の名前は書かなくてもかまいません）

> ルーターの再起動などでアドレスが変わると、印刷したQRコードが使えなくなることがあります。そのときは印刷し直してください。

## 使い方

### 見る
- アルバム → フォルダ の順にタップして開きます。
- 写真や動画をタップすると大きく表示されます。
- 左右にスワイプ（PCなら ← → キーや画面の矢印）で前後の写真に移動します。
- 上の「すべて / 写真 / 動画」で絞り込み、「新しい順」などで並び順を変えられます。

### ギャラリーモード（スライドショー・フォトフレーム）
写真を画面いっぱいに表示して、自動で次々に切り替えます。タブレットや PC をフォトフレームのように使えます。

スライドショーでは、写真を画面に合った大きさに縮めて表示します。そのため通信量が少なく、古いタブレットでも軽く動きます。一度表示した写真は端末に残るので、2周目からはすぐに表示されます。印刷とダウンロードは元の画質のままです。

**始め方**
- トップ画面の **「すべての写真でスライドショー」**（または右上の **「ギャラリー」**）… すべてのアルバムの写真を、中のフォルダも含めて表示
- フォルダを開いて右上の **「ギャラリー」** … そのフォルダの写真を表示
- 「選択」で写真を選んで、下の **「ギャラリー」** … 選んだ写真だけを表示
- 写真を大きく表示しているときの右上の **「⋯」→「ここからギャラリーで見る」** … その写真から始める

**操作**
- 画面をタップ（PCならマウスを動かす）すると、操作ボタンが出てきます。しばらくすると自動で隠れます。
- 画面の **右はし・左はしをタップ**、**左右にスワイプ**、**マウスホイール** で前後の写真に移動できます。
- **ダブルタップ**（ダブルクリック）で写真を拡大。もう一度タップで元に戻ります。
- 下のボタン：前へ・再生／一時停止・次へ、**−／＋**（切り替えの速さ）、シャッフル、一覧、設定（⚙）、全画面
- 下に並ぶ小さな写真をタップすると、その写真へ移動します。**一覧**ボタンで全体を見て選ぶこともできます。
- 右上の **「⋯」** で、表示中の写真のダウンロード・アルバムで開く・印刷・**スマホで開く（QRコード）**・今後表示しない、ができます。
- 上にスワイプすると設定、下にスワイプすると終わります。左上の **✕** でも終われます。

**設定（⚙）でできること**
- **おすすめの設定**：「フォトフレーム」「スライドショー」「パーティー」「置き時計」をワンタッチで切り替えられます
- **切り替え**：間隔（3秒〜5分）、効果（フェード・スライド・ズーム・円形・フリップなど17種類、ランダムも）、速さ
- **写真の動き**：ゆっくりズーム・ズームアウト・横に流れる・ランダム・動かさない、動きの強さ
- **表示のしかた**：1枚ずつ／縦長は2枚並べる／2枚ずつ／4枚ずつ、全体表示／画面いっぱい、背景（ぼかし・写真の色・黒・白）、白いふち・ポラロイド風、角を丸く、影、色調（モノクロ・セピアなど）、周辺減光、フィルムの粒子
- **情報の表示**：時計・今日の日付・写真の日付・「◯年前」・ファイル名・フォルダ名・枚数、文字の位置と大きさ、次の写真の予告
- **順番と選び方**：フォルダの順・新しい順・古い順・名前順・シャッフル、横長／縦長だけ、年・最近・**今日の思い出**（同じ月日の写真）で絞り込み、最後で止める
- **動画**：動画も流す、音を出す（動画は切り替えの間隔に関係なく、最後まで再生してから次へ進みます。再生できない動画は飛ばします）
- **音楽（BGM）**：この端末の音楽ファイルを選んで流せます（複数選ぶと順番に流れます）。音量、一時停止で音楽も止める
- **フォトフレーム**：おやすみタイマー、夜は画面を暗くする、明るさ、新しい写真を自動で取り込む、**フォトフレーム用のアドレス**（開くとすぐギャラリーが始まるアドレスとQRコード）

> 設定は次回も引き継がれます。「設定をすべて最初に戻す」で元に戻せます。
> 追加した機能の全一覧は [docs/gallery-features.md](docs/gallery-features.md) にあります。

### ダウンロードする
- **1枚だけ**：写真を大きく表示して、右上の **「ダウンロード」** を押します。
- **まとめて**：右上の **「選択」** を押して（スマホなら写真を長押しでもOK）、ほしい写真をタップしていき、下の **「まとめてダウンロード」** を押します。
  まとめてダウンロードしたものは、1つの ZIP ファイルになります。
  - iPhone の場合：「ファイル」アプリの「ダウンロード」に保存されます。ZIP ファイルをタップすると中身が取り出せます。
  - Android・PC の場合：ZIP ファイルを開くと中身が見られます。

> **iPhone で撮った写真（HEIC形式）をダウンロードするとき**
> 自動で **JPEG に変換して** 保存されます。Android や Windows のパソコンでもそのまま開けます（まとめてダウンロードするときも同じです）。

> iPhone で写真を「写真」アプリに保存したいときは、写真を大きく表示した状態で、写真を長押しして「"写真"に追加」を選ぶと簡単です。

### アップロードする（許可したフォルダのみ）
- フォルダを開いて、右上の **「アップロード」** を押し、送りたい写真や動画を選びます。
- 一度にたくさん選べます。画面上に進み具合（○○%）が表示されます。
- PC の場合は、写真や動画のファイルを画面にドラッグ＆ドロップしても追加できます。
- 右上の **「フォルダ作成」** で、新しいフォルダを作れます。
- 同じ名前のファイルがすでにあるときは、「名前 (1).jpg」のように別の名前で保存されます（上書きはされません）。
- 1件ずつ順番に送ります。途中で通信が途切れても、ほかの写真は追加されます。追加できなかったものがあると、最後に結果が表示されます。

> **Android の Google フォトから選ぶとき**
> Google フォトの写真のうち、クラウドにだけあってスマホに保存されていないものは、選んでも読み込めないことがあります（結果に「読み込めなかったもの」と出ます）。
> そのときは、Google フォトで写真を開いて「︙」→「ダウンロード」でスマホに保存してから、もう一度選んでください。

### 写真を編集する
写真を大きく表示して、右上の **「編集」** を押します。下の5つのタブで編集できます。

- **フィルター** … 「ビビッド」「ヴィンテージ」「モノクロ」など、写真の雰囲気をワンタッチで変えます。選んだあとに出てくる「強さ」で効き具合を調整できます。
- **調整** … 明るさ・コントラスト・彩度・暖かさ・色かぶり・ハイライト・シャドウ・フェード・周辺減光・シャープ・粒子を、スライダーで細かく調整できます（変更した項目には青い点が付きます）。
- **切り抜き** … 枠の四隅をドラッグして切り抜きます。「1:1」「4:5」などの比率を選ぶと、その形で切り抜けます。左右の回転・反転と、傾きの補正もできます。
- **ペン** … 写真に指やマウスで自由に書き込めます。
  - 種類：**ペン**（くっきりした線）、**マーカー**（透ける太い線）、**ネオン**（光る線）、**消しゴム**（なぞった線を消す）
  - 色を10色から選べ、「太さ」で線の太さを変えられます
  - **「ひとつ戻す」** で直前の書き込みを取り消せます
- **スタンプ** … ハートや星、顔などのスタンプや、文字を写真に乗せられます。
  - スタンプを選ぶと写真の真ん中に置かれます。ドラッグで好きな場所に動かせます
  - **「Aa 文字を入れる」** で文字を入れられます。文字の色と、見た目（縁取り・背景付き・シンプル）を選べます
  - 置いたものをタップすると選択され、「大きさ」「角度」の調整、複製、削除ができます。終わったら「完了」を押します

便利な操作
- 写真を **長押し**（PCならマウスのボタンを押したまま）すると、編集前の写真と見比べられます。
- スライダーの数字をダブルクリックすると、その項目が0に戻ります。
- 上の **「リセット」** で、すべての編集を最初に戻せます。

最後に右上の **「保存」** を押して、保存の方法を選びます。
- **別の写真として保存** … 「元の名前_編集.jpg」として、同じフォルダに保存します（アップロードを許可したフォルダのみ）
- **元の写真を上書き** … 元の写真はこのPCのごみ箱に移ります（削除・名前変更を許可したフォルダのみ）
- **この端末にダウンロード** … アルバムには保存せず、手元のスマホやPCに保存します（どのフォルダでも使えます）

### 印刷する
- **1枚だけ**：写真を大きく表示して、右上の **「⋯」→「印刷」** を押します。
- **まとめて**：「選択」で写真を選んでから、下の **「印刷」** を押します。

印刷画面が開くので、左側（スマホでは上側）で次のことを調整します。右側には、実際に印刷される形が表示されます。

- **用紙** … 用紙サイズ（A4・L判・2L判・はがき など）と、用紙の向き（縦・横）
- **レイアウト** … 1枚の用紙に何枚の写真を並べるか（1枚〜30枚）、同じ写真を何枚ずつ印刷するか、ふちの余白と写真どうしの間隔
- **写真の向きと大きさ** … 写真全体を表示するか、枠いっぱいにするか。写真の向きを枠に合わせて自動で回転するか。プレビューの写真をクリック（タップ）すると、その写真だけ90°ずつ回転できます。
- **印刷位置** … 枠の中で写真を寄せる位置（上・中央・下／左・中央・右）と、全体の位置の微調整（ずれる場合に少しずつ動かせます）
- **その他** … 写真の下に日付やファイル名を入れる、切り取り線を入れる

調整が終わったら右上の **「印刷する」** を押します。プリンターの印刷画面が開いたら、次のように設定してください。
- **用紙サイズ**：印刷画面で選んだものと同じ（例：L判）
- **余白**：「なし」
- **倍率**：「100%」または「実際のサイズ」
- **用紙の種類**（写真用紙・普通紙など）：プリンターの設定で選びます

> ふちなし（余白0mm）で印刷するには、プリンターがふちなし印刷に対応している必要があります。
> 設定内容は次回も引き継がれます。

### 削除・名前を変える（許可したフォルダのみ）
- 「選択」で写真を選んでから、下の **「削除」** または **「名前を変更」** を押します。
- 写真を大きく表示しているときは、右上の **「⋯」→「削除」** でも削除できます。
- 削除した写真や動画は、このPCの **「ごみ箱」** に移動します。間違えて消しても、ごみ箱から元に戻せます。

---

## 終了する

起動したときに開いた **黒い画面を閉じる** と終了します。
終了している間は、スマホなどからは見られません。また見たいときは、もう一度 `start.bat` をダブルクリックしてください。

## 困ったとき

**スマホから開けない**
- このPCで `start.bat` を起動しているか（黒い画面が開いているか）確認してください。
- スマホがこのPCと同じ Wi-Fi につながっているか確認してください（モバイル通信では開けません）。
- 起動時の警告で「アクセスを許可する」を押さなかった場合は、Windows の「設定」→「プライバシーとセキュリティ」→「Windows セキュリティ」→「ファイアウォールとネットワーク保護」→「ファイアウォールによるアプリケーションの許可」で、「Node.js」の「プライベート」にチェックを入れてください。

**写真の一部が表示されない**
- iPhone で撮った「HEIC（HEIF）」形式の写真も、一覧・大きな表示・ギャラリー・編集・印刷で使えます。初めて表示するときは変換のため少し時間がかかります。
- それでも表示されない写真は、ファイルが壊れているか、対応していない形式の可能性があります。その場合もダウンロードはできます。

**動画が再生できない**
- 動画の形式によってはブラウザで再生できないことがあります。ダウンロードして、お使いの動画アプリで再生してください。

**アドレスが変わった**
- ルーターの再起動などで、このPCのアドレス（192.168.○○.○○ の部分）が変わることがあります。管理画面で新しい QRコードを読み取り直してください。

**管理用パスワードを忘れた**
- このアプリのフォルダにある `data` フォルダの中の `config.json` を削除すると、最初の設定からやり直せます（登録したフォルダの設定も消えます。写真や動画は消えません）。

**古いタブレット（Fire タブレットなど）で見たい**
- Fire OS 4（Kindle Fire HD / HDX など 2013〜2014年ごろの Fire タブレット）の Silk ブラウザでも見られるようにしています。古いブラウザで開くと、自動で古いブラウザ向けの画面に切り替わります。
- とても古いブラウザ（Silk 3 など）では、**見るためのかんたん版**が開きます。かんたん版でできるのは次のことです。
  - アルバムやフォルダを開いて、写真や動画を見る（左右にスワイプで前後の写真へ）
  - 1枚ずつダウンロードする
  - スライドショー（切り替えの間隔・シャッフル・中のフォルダの写真も流す・動画も流す・動画の音を出す、を選べます）。トップ画面の「すべての写真でスライドショー」で、全アルバムの写真を流せます
  - 動画は最後まで再生してから次へ進みます。動画が自動で始まらないときは「画面をタップすると動画を再生します」と出るので、画面をタップしてください（しばらくタップしないと次へ進みます）。
  - 古いタブレットで再生できない動画（最近の iPhone で撮った動画など）は、自動で飛ばします。
- アップロード・まとめてダウンロード・編集・印刷・削除などは、かんたん版ではできません。スマホやPCから行ってください。
- この機能を使うには、このPCで `start.bat` から起動し直してください（初回は必要な部品をインターネットから取り込むので、少し時間がかかります）。
- 「このブラウザでは表示できません」と出たときは、画面の下に出ている灰色の枠の内容を写真に撮っておくと、原因を調べるのに役立ちます。
- 古いタブレットは動きがゆっくりなことがあります。ギャラリーモードは、設定で「切り替え効果」を「フェード」、「写真の動き」を「動かさない」にすると軽くなります。

**管理画面はどこから開ける？**
- アルバムのトップ画面の右上にある「管理」から開けます。
- このPCからは `http://localhost:8080/admin` でも開けます。
